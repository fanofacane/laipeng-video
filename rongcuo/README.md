# 人生的容错率（竖屏 1080×1920，130 秒）

风格对标参考视频：暗色暖黑底、发光金线、衬线字幕逐字模糊浮现、关键否定词用红色模糊印章砸入。
开头动画同参考的“理想人生时间线”：一条线自下而上生长，点亮 18/22/26/30 岁的节点 →
“选错了”红章砸在第一个节点上 → 每个节点长出分叉 → 一个决定连向“未来”，更多力量（时代、运气、遇见的人…）一起汇入。

| 段落 | 画面 |
|---|---|
| 人害怕犯错… | 一次选择被直线推演成“一生的结局”；三条“选错专业→没有前途”式的必然链 |
| 你会继续行动… | 推理链裂开，“你”沿弯曲的路前进，吸收经验和能力，一次次分叉；“失误”被等同于一生失败时，假设的此后是一条灰色直线 |
| 提前拥有所有答案 | 黑暗中的关系网，只有“认知”那圈光照得见；20 岁→25 岁，光圈变大、路线调整 |
| 已经付出的代价 | 过去的投入（时间、精力、金钱、感情）挽回不了；看前方的分支，而过去渐暗 |
| 容错率大≠没有代价 | 一棵树，有两枝断掉变红，但更多枝条继续长出来 |
| 关系结束 / 尝试失败 | “不值得被爱”“没有能力”的红章砸下后消散，“你”依旧亮着 |
| 具体的问题 | 红色的自我否定收缩成一个具体的点，长出承担 / 弥补 / 调整；“全面否定”砸下又消散 |
| 可修正 / 不可逆 | 上：允许试错的小绕路；下：在红色不可逆边界前停下 |
| 结尾 | 过去的路有红点也没关系，继续向前，新的线从“你”身上长出来，铺成一张网；片尾回到“人生的容错率，大到超乎你的想象” |

## 目录
- `src/lines.txt` 文案（`#` 分段）
- `src/timing.js` 配音逐字时间（由 `tools/tts.py` 生成）
- `src/engine.js` 画布引擎（发光层 + 文字层 + 字幕，每帧只由时间 t 决定）
- `src/scenes.js` 分镜
- `audio/voice.wav` 配音（edge-tts 云希，-6% 语速），`audio/music.wav` 合成氛围配乐 + 红章闷响
- `out/人生的容错率.mp4` 成片

## 重新生成
```bash
python3 tools/tts.py                     # 配音 + 时间轴（改了文案后删掉 audio/lines 对应文件再跑）
python3 tools/fonts.py <NotoSerifSC-*.otf 目录>   # 截取用到的字
python3 tools/audio.py                   # 配乐 + 混音 → audio/mix.wav
node tools/render.mjs stills /tmp/st 5 20 60      # 抽帧检查
node tools/render.mjs video out/a.mp4 0 3920      # 渲染（可分段并行后 concat）
ffmpeg -i out/a.mp4 -i audio/mix.wav -map 0:v -map 1:a -c:v libx264 -crf 21 -c:a aac -b:a 192k -shortest out/人生的容错率.mp4
```
预览：浏览器打开 `src/index.html?play`，点击播放 / 暂停。
